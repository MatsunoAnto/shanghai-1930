# 弄堂剪报 · 玩法设计

本文件规定游戏体验、核心流程与范围。运行方式和现有操作见 [README](../README.md)，画面与表现要求见 [美术方向](ART_DIRECTION.md)。

## 1. 游戏定位

玩家扮演一名小报童，在 1930 年代的老上海街区中横向行走，经历春、夏、秋、冬四个季节。街坊的谈话、墙上的旧海报和流转的纸本读物，为玩家提供可以剪取的图像；玩家把收集的元素拼贴成社区露天电影院的海报。

体验重点是观察街区、与人交往、挑选图像和动手构图。玩家收集的不只是物品数量，而是能够重新组合、表达自己想法的图像元素。

## 2. 已确定的核心流程

**四季中的老上海横版探索 → 发现或获得可剪切物品 → 自由剪切 → 收集元素 → 为社区露天电影院拼贴海报。**

两条素材获取路径汇入同一套剪切与拼贴流程：

| 路径 | 玩家行为 | 得到什么 |
| --- | --- | --- |
| 场景中的旧海报 | 接近可交互的墙面海报，打开查看并圈选 | 海报中的图像剪片 |
| NPC 提供的纸本 | 接近 NPC，进入对话，获得杂志、宣传册等可剪切物品 | 可供查看和剪切的纸本内容 |

NPC 本身不是剪切对象。对话提供人与街区的联系，也可以成为获得纸本素材的途径；不要求每一次谈话都发放物品。

## 3. 目标与当前实现

“已确定”表示设计方向；“已实现”只描述当前仓库中的原型，不代表完整游戏或人类验收完成。

| 系统 | 已确定的目标 | 当前原型 |
| --- | --- | --- |
| 街区探索 | 老上海横版探索，建筑遮挡衔接地点 | 已实现站内月台、里弄、影院门口三个地点 |
| 四季 | 在春、夏、秋、冬中探索 | 未实现季节内容或推进流程 |
| 墙面海报 | 从可交互的旧海报自由剪切 | 已实现，每个地点一张 |
| NPC | 场景中可交互，交互后进入对话模式 | 未实现 NPC 或对话系统 |
| 其他纸本 | 从 NPC 获得杂志、宣传册等可剪切内容 | 未实现获取、查看或保管这些纸本的流程 |
| 自由剪切 | 鼠标圈出想要剪下的区域 | 已实现不规则、凹形和自交轮廓的圈选、预览、重画与确认 |
| 元素收集 | 保存剪片，供后续拼贴使用 | 已实现报袋展示与跨地点保留 |
| 海报拼贴 | 为社区露天电影院制作海报 | 未实现拼贴工作台、完成展示或交付流程 |

当前只有三个海报来源，所以报袋显示三个格子；每张海报只能确认剪下一片。它们是原型限制，不是完整游戏的固定容量或剪切次数规则。

当前剪片和墙面缺口只在本次页面运行期间保留。刷新页面或重新开始会清空，尚无跨会话存档。

## 4. 横版探索与地点

- 玩家沿画面中的水平步行带左右移动；场景保持侧面视角。
- 走到有相邻地点的一侧边界后，角色先被前景墙角、柱子等建筑遮住，再切换到下一地点，并从对应一侧走出。
- 场景切换由行走触发，不能用目的地菜单代替这一体验。没有相邻地点的端点应明确阻挡继续前进。
- 墙上海报与 NPC 都是探索中的交互对象，需要能与纯装饰分辨；具体表现遵循美术方向。
- 车站是站内空间，当前表现为有列车、顶棚和售票窗的月台。

现有地点顺序为 **车站站内 ↔ 里弄 ↔ 影院门口**。这条关系描述当前原型，不把最终街区数量和地点连接方式锁定为三个。

当前“影院门口”是一处已有的建筑场景。最终海报服务的对象是**社区露天电影院**；露天放映空间、工作台和成品展示尚待设计，不能把现有门面视为已经完成该目标。

## 5. NPC 与对话

### 已确定

接近并与 NPC 交互后进入对话模式。NPC 可以向玩家提供杂志、宣传册等纸本素材，玩家再从这些物品中自由剪取图像。

### 后续实现建议

以下作为第一版对话流程的建议基线，具体输入和赠予条件在实现任务中确定：

1. 玩家主动交互，显示当前说话者和对话内容。
2. 对话期间暂停角色移动、边界换场和剪切输入，避免同一次按键作用于多个模式。
3. 若本段对话提供物品，清楚说明获得的纸本；记录获取结果，避免因重复点击同一句话意外重复发放。
4. 对话结束后，玩家可以主动查看获得的纸本，进入统一的剪切流程。不要在同一次操作中悄悄跳过对话并剪下素材。
5. 允许退出对话并回到街上；退出未完成的对话不应误判为已经领取物品。

NPC 的人数、身份、完整台词、赠予条件和能否重复赠予目前均未确定。不默认增加好感度、交易货币或一串强制支线任务。

## 6. 自由剪切

### 共同体验

可剪切物品打开后，玩家看到可辨认的正面内容。玩家按住鼠标自由描画轮廓，松开后闭合选区，先查看剪片预览，再决定确认、重画或取消。触屏可沿用手指圈选。

剪切沿玩家画出的区域进行，不能退回预制矩形、固定图案按钮或整张自动收集。剪片保留原图中所选部分的颜色和图像，轮廓外透明。

### 当前原型规则

- 点击、直线或过小过细的圈选不会生成有效剪片。
- 确认后，同一轮廓用于报袋里的剪片和墙上海报留下的缺口。
- 确认前取消或重画不改变来源图像、不增加收集数量。
- 已剪海报可重新查看；离开并返回地点后，缺口仍保留。

### 扩展到纸本时需确定

杂志和宣传册复用同一套圈选、预览与确认体验，但多页浏览、同页多次剪取、剩余纸张保留方式尚未确定。不要直接把当前“每张只能剪一次”的限制当成完整纸本系统规则。

## 7. 元素收集

收集结果应是可识别、可继续用于拼贴的图像剪片。报袋是当前原型的展示方式，不代表未来必须增加复杂背包管理。

后续实现建议保留剪片与来源的对应关系，使重复领取、重复确认和切换地点不会混淆素材状态。对话、纸本查看和拼贴之间切换时，不应丢失已经确认的剪片。

完整游戏的容量、重复剪片处理、使用后是否消耗、跨季节携带及跨会话保存均待定。第一轮拼贴实验应优先验证拿到的剪片能被实际使用。

## 8. 社区露天电影院海报

拼贴是探索与收集的目的。玩家将获得的图像元素放到海报版面中，组合成服务于社区露天电影放映的作品，并能看到完整成品。

第一轮拼贴实验建议至少支持：选择已有剪片、放入版面、调整摆放位置、撤回或移除本次放置、查看完整海报。操作应允许修改，避免一次误放使作品无法继续编辑。

缩放、旋转、叠放顺序、固定文字与自由输入、作品数量及导出方式尚未定案。评分、限时、必需图案数量和精确完成判定也没有确定，不应在实现时自行加入。

露天电影院的活动主题、海报如何交付与展示、何时进入下一阶段，需要与第一版拼贴结果一起确定。单纯把报袋填满不等于完成了海报。

## 9. 四季与内容组织

四季是完整游戏的体验范围：玩家应能感受到春、夏、秋、冬中的街区变化，并接触与当季生活有关的纸本内容和人物互动。具体画面规范见 [美术方向](ART_DIRECTION.md)。

**制作建议，尚非固定关卡结构：**优先复用已能行走的地点，通过季节布景、配色、NPC 对话和纸本内容的变化形成新一轮探索；确有体验需要时再新增地点。四季不等于需要制作十二张独立地图。

季节按什么顺序或条件推进、能否返回上一季、素材是否跨季节保留，以及每季对应多少次放映或多少张海报，均待定。未确定前不把季节切换实现为现实时间等待、倒计时或自动删除素材。

## 10. 建议的开发顺序

先完成一个季节中的完整小流程，再扩展内容：

1. 保留现有横版探索和墙面剪切，加入一名可进入对话模式的 NPC，用一件纸本验证另一条素材获取路径。
2. 让墙面剪片与纸本剪片进入同一份可用素材集合。
3. 做出可摆放剪片并查看成品的海报工作台，让探索结果真正成为社区露天电影院的海报。
4. 验证取消、重复交互和场景往返不会损坏素材，再确定季节推进和保存方式。
5. 按确定后的结构补齐四季内容与人物互动。

这是一条控制制作量的实施建议，不把“一名 NPC、一件纸本、一张海报”规定为完整游戏的总量。战斗、开放大地图、复杂经营和大量支线不属于当前核心流程，不随本轮文档自动进入开发范围。

## 11. 下一步需要决定的问题

| 问题 | 影响 |
| --- | --- |
| 四季如何推进，是否允许回访？ | 场景内容切换与进度保存 |
| 纸本能否多页、多次剪切，素材如何重复获得？ | 查看方式、来源状态与剪片数量 |
| 拼贴第一版需要哪些编辑操作？ | 工作台大小与交互复杂度 |
| 海报的主题、完成条件与展示地点是什么？ | 核心流程的收尾与露天电影院表现 |
| 剪片是否消耗、跨季节保留，何时保存？ | 素材管理与长期游玩连续性 |

这些问题未决定前，文档与交付说明应保持“待定”，不能用实现细节替代产品决定。
